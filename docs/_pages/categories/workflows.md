## What is a Workflow?
A workflow is a common tool in geospatial and other technical methods to break down a larger problem into smaller steps. When a task requires more than one tool to accomplish, using a workflow to visualize the inputs, outputs, and details required for each tool can be incredibly useful. A fun example below shows the layout of workflows for the Geospatial Methods Crosswalk.

Workflows take a multi-step problem, list it's inputs and steps, and provide guidance on what is needed to accomplish each step, making them an asset in geospatial work
